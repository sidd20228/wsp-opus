**Strategy.** The player never moves sideways. It stays in its start column, column 5, and only moves up or down. Each row from 1 to 8 holds at most one entity. The trail cell shows which way that entity is moving, so for each row the network can tell how many moves it will take to reach column 5 (call this k).

- A row is lethal if an enemy is at column 5 (k=0), or is one move away and approaching (k=1).
- A row with approaching treasure is attractive. It is also safe, because a row with treasure in it cannot contain an enemy.
- The player picks the best of the rows above, current and below.
- Column 5 sits at least 3 moves from where new entities appear, so a new arrival can never kill the player without warning.
- Left, right and fire are never chosen, so sticky repeats can never move the player sideways.

**Layer 1 (32 units).** Every row unit adds enemy (or treasure) position weights to trail weights. I solved these as chains, so every entity moving away sums to exactly the baseline. Every approaching position at distance k gets exactly its target value. Trail weights are never positive, so the other entity type in a row cannot cause a false signal.

- **Units 0–7, H_r (enemy threat now) for rows 1–8.** The output is about +1 when the row is lethal, and -1 when it holds no threat. In between: k=2 gives H+1 = 0.25, k=3 gives 0.15, k=4 gives 0.05, and k=5 gives 0.015.
- **Units 8–15, Gl_r (approaching treasure).** Gl+1 is 1.6 for k≤1, 1.0 for k=2, 0.7 for k=3, 0.5 for k=4, and 0.4 for k=5.
- **Units 16–23, N_r (threat on the next step).** N+1 is 2 for k=1, 1.4 for k=2, 1 for k=0, and 0.2 for k=3.
- **Units 24–31, P_y (player row).** The output is +1 when the player is in row y, and -1 otherwise.

**Layer 2 (24 units).** There is one unit Q(y0, δ) for each player row y0 and each choice δ of up, stay or down. A unit is active only when the player is in row y0, through gate weight 6. Inactive units sit at exactly -1, and the output bias of 700 cancels them. An active unit scores the target row:

- -1·(H+1) for the target row's own threat (lethal gives -2).
- +0.25·(Gl+1) for treasure in the target row.
- -0.06·(N+1) for each neighbour of the target row, which measures escape routes.
- -0.2·(N+1) for the row beyond, in the direction of the move. This covers the 10% chance that a sticky repeat carries the player one row further.
- +0.1 or +0.05 for treasure two or three rows away in the move direction.
- -0.1 for each missing neighbour at the top or bottom edge.
- +0.015 for no-op.

**Outputs.** The logits for no-op, up and down are 100·Q. A lethal option always sits at least 22 logits below any non-lethal one. Left, right and fire are set to -200.
